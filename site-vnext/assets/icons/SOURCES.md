# Public icon sources

Lucide Icons, version 0.468.0. SVG files are saved locally so the deck does not
depend on a third-party script or CDN at presentation time.

- Source: https://github.com/lucide-icons/lucide/tree/0.468.0/icons
- License: https://lucide.dev/license
- Included notices: LICENSE in this directory (ISC and applicable Feather MIT notices).

Icons identify roles and functions. A building icon beside a mall name is a
generic visual cue, not that organisation's logo or an endorsement.
